# CryptoGraphic 📊💰

> **Dynamic cryptocurrency price visualization tool** - Track and visualize your favorite crypto assets over custom time periods with beautiful, interactive charts.

---

## ✨ Features

- 🎯 **Multi-Crypto Support** - Visualize any cryptocurrency in real-time
- 📈 **Custom Time Ranges** - Choose your own time period for analysis (days, weeks, months)
- 🎨 **Dynamic Graphics** - Beautiful, auto-generated charts for easy trend analysis
- ⚡ **Fast & Lightweight** - Efficient Python-based processing
- 💾 **Data-Driven** - Powered by real cryptocurrency market data

---

## 🚀 Quick Start

### Installation

```bash
git clone https://github.com/Gabman8/CryptoGraphic.git
cd CryptoGraphic
pip install -r requirements.txt
```

### Usage

```python
from cryptographic import CryptoGraphic

# Create a graphic for Bitcoin over the last 30 days
cg = CryptoGraphic()
cg.generate_chart('bitcoin', days=30)
```
